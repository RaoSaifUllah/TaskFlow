# ADR-001: Modular monolith and separate worker

Status: accepted baseline, 2026-10-01.
Implementation evidence: see ../Implementation-Status.md; acceptance is not a verification claim.

## Decision
Keep API and background worker as distinct executable hosts, with Domain, Application and Infrastructure projects.

## Rationale and consequences
Simple self-hosting and atomic database changes without a broker. API and worker deploy independently.

Source: document/02-Software-Design.md. No deviation from the supplied architecture.
