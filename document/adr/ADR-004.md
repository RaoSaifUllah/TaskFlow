# ADR-004: Anchored recurrence skips missed slots

Status: accepted baseline, 2026-10-01.
Implementation evidence: see ../Implementation-Status.md; acceptance is not a verification claim.

## Decision
Generate one next schedule-anchored occurrence strictly after the current anchor and completion clock; skip missed slots and RFC-invalid dates/times.

## Rationale and consequences
Month-end does not clamp. Ambiguous fall-back time selects the first occurrence. Integration and timezone evidence pending.

Source: document/02-Software-Design.md. No deviation from the supplied architecture.
