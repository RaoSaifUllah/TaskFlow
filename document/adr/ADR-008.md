# ADR-008: Isolated PostgreSQL verification and local provisioning helper

Status: accepted, 2026-10-01.

## Context and decision
Docker, local PostgreSQL server binaries and WSL distributions were unavailable.
The owner explicitly supplied a temporary dedicated Neon database and authorized
restricted-role provisioning and a separate disposable test database. Use it for
real PostgreSQL verification without substituting SQLite. This is a development
environment decision; self-hosted deployment remains PostgreSQL/Compose.

TaskFlow.DbTool is a development/operations console tool composing Infrastructure.
It creates random scoped role/database names, writes generated credentials only
to ignored local settings, applies migrations explicitly, and prints sanitized
outcomes. The API and worker never migrate automatically. Its rollback mode
validates the provisioned test database name/host and refuses the runtime database.

## Consequences
The owner says the supplied database will be deleted in 30 days. It is not a
production hosting choice. Local Compose verification and backup/restore remain
required. Operational changes are authorized only for the dedicated TaskFlow
database/project; no unrelated Neon data may be changed. Owner credentials must
never become API/worker write/read credentials or appear in published files.
