# ADR-005: Private Inbox and inherited project access

Status: accepted baseline, 2026-10-01.
Implementation evidence: see ../Implementation-Status.md; acceptance is not a verification claim.

## Decision
Each workspace member has an Inbox private to that user. Project tasks inherit creator, owner/admin and explicit share policies.

## Rationale and consequences
Admin roles do not grant access to other private Inboxes. Guest shares remain read-only. Apply policy to reads, files, search and queued delivery.

Source: document/02-Software-Design.md. No deviation from the supplied architecture.
